# Сейф: введення пін-коду енкодером

ESP32-S3 (YD-ESP32-S3 N16R8), ESP-IDF v6.0. Енкодер KY-040, пасивний бузер, серво SG90 як замок.

## Підключення

| Компонент | Пін модуля | ESP32-S3 |
|---|---|---|
| Енкодер KY-040 | CLK / DT / SW | GPIO4 / GPIO5 / GPIO6 |
| | + / GND | 3V3 / GND |
| Бузер (через NPN) | R1 1 кОм → база Q1 BC547 | GPIO7 |
| | колектор Q1 → BZ1 → +5V, D1 1N4148 паралельно BZ1 | |
| Серво SG90 | PWM / + / GND | GPIO14 / 5V / GND |
| C1 470 мкФ | між 5V і GND біля серво | |

## Правила введення

- Перший тік (у будь-який бік) починає цифру зі значенням **0**.
- Кожен наступний тік у тому ж напрямку: **+1**. Після 9 іде 0 (циклічно).
- Тік у **протилежному** напрямку підтверджує цифру і починає наступну з 0.
- Після підтвердження останньої цифри код перевіряється одразу.
- **Кнопка**: скидання введення. Рахується як спроба.
- **3 спроби**. Після них грає сирена, і сейф блокується до перезавантаження (кнопка EN на платі).
- **Правильний код**: мелодія, серво повертається у положення «відкрито». Кнопка у відкритому стані закриває замок.

Приклад для коду `2 0 2 6`:

| Дія | Тіків | На екрані |
|---|---|---|
| CW | 3 | `0` → `1` → `2` |
| CCW | 1 | `2 0` |
| CW | 3 | `2 0 0` → `2 0 1` → `2 0 2` |
| CCW | 7 | `2 0 2 0` … `2 0 2 6` |
| CW | 1 | `2 0 2 6  -> OK` |

Код, кількість спроб і кути серво задаються на початку `main/main.c`.

## Структура

```
main/
  main.c      — з'єднує логіку із залізом: події → звук, серво, лог
  safe.c/h    — логіка сейфа (скінченний автомат), без залежності від ESP-IDF
  encoder.c/h — KY-040: переривання + квадратурне декодування, кнопка з антибрязкотом
  buzzer.c/h  — пасивний бузер на LEDC (таймер 1), мелодії
  servo.c/h   — SG90 на LEDC (таймер 0), 50 Гц
```

## Збірка і прошивка

```
idf.py set-target esp32s3
idf.py build
idf.py -p COM6 flash monitor
```

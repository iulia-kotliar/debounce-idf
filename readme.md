# Модуль 3.4 — Програвання звуку на зумері (PWM)

Простий синтезатор на ESP32-S3: пасивний зумер грає головний мотив «Польоту валькірій» Ріхарда Вагнера (спрощено). Висоту ноти задає частота PWM-сигналу, який генерує периферія LEDC.

## Обладнання

| Компонент | Кількість | 
|---|---|
| ESP32-S3 (YD-ESP32-S3 N16R8) | 1 |
| Пасивний зумер | 1 | 
| NPN-транзистор S8050 | 1 | 
| Резистор 1 кОм | 1 | 
| Макетна плата, дроти | | 

## Схема підключення

```
 3V3 ───────────────┐
                    │
                 ┌──┴──┐
                 │  +  │
                 │ BUZ │  пасивний зумер
                 │  −  │
                 └──┬──┘
                    │
                    C
 GPIO4 ──[ 1 кΩ ]── B   Q1 S8050 (NPN)
                    E
                    │
 GND ───────────────┘
```

| ESP32-S3 | Куди |
|---|---|
| 3V3 | «+» зумера |
| GPIO4 | через 1 кОм на базу Q1 |
| GND | емітер Q1 |
| — | колектор Q1 → «−» зумера |

## Як це працює

1. **LEDC-таймер** генерує прямокутний сигнал з частотою ноти (`ledc_set_freq`).
2. **Duty 50 %** дає зумеру максимальну гучність. Duty 0 означає тишу.
3. **Партитура** зберігається як масив структур `{частота, тривалість}`.
4. Між нотами робиться коротка пауза (15 мс), щоб кожна нота мала чітку атаку. Пауза забирає кінець ноти, а не додається після неї, тому ритм не «пливе».

Мотив упізнається за ритмом галопу: коротка–довга, коротка–довга–ДОВГА–ДОВГА. Одна фраза описується макросом:

```c
#define GALLOP(low, root, third) \
    { low, S }, { root, L }, { low, S }, { root, L }, { third, H }, { root, H }
```

Фраза повторюється на акордах, які піднімаються: си мінор → ре мажор → фа-дієз мінор → кульмінація, потім повертається до си мінору.

### Ноти

| Нота | F#4 | B4 | D5 | F#5 | A5 | B5 |
|---|---|---|---|---|---|---|
| Частота, Гц | 370 | 494 | 587 | 740 | 880 | 988 |

### Ритм

| Позначка | Тривалість | Значення |
|---|---|---|
| `S` | 1 × `TEMPO_UNIT` | коротка (затакт) |
| `L` | 3 × `TEMPO_UNIT` | довга |
| `H` | 6 × `TEMPO_UNIT` | витримана |

За замовчуванням `TEMPO_UNIT = 110` мс. Щоб пришвидшити, зменш це значення.

## Збірка і запуск

Потрібен ESP-IDF v5.x.

```bash
idf.py set-target esp32s3
idf.py build
idf.py -p <PORT> flash monitor
```

Для IDF старіших за 5.3 заміни в `main/CMakeLists.txt` `esp_driver_ledc` на `driver`.

Рекомендовано: у `idf.py menuconfig` → Component config → FreeRTOS → Kernel встановити `configTICK_RATE_HZ = 1000`. З тіком 100 Гц затримки округлюються до 10 мс, і ритм стає менш точним.

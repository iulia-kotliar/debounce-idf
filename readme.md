# Модуль 3.1 — Проста ковзна середня (SMA)

Автоматичне керування світлодіодом за рівнем освітленості на ESP32-S3.
Значення з фоторезистора (LDR) зчитуються через ADC1 в режимі oneshot, фільтруються простою ковзною середньою (SMA), а світлодіод перемикається з гістерезисом, щоб не мерехтіти при незначних коливаннях освітленості.

## Апаратна частина

**Плата:** YD-ESP32-S3 N16R8

### Схема

```
        3V3
         │
        ┌┴┐
        │ │  LDR
        └┬┘
         │
         ├──────────────► GPIO4  (ADC1_CH3)
         │        │
        ┌┴┐      ═╪═ 100 nF (опційно)
        │ │ 10kΩ  │
        └┬┘       │
         │        │
        GND ─────GND


   GPIO16 ───[ 330Ω ]───►|─── GND
                        LED
```

### Підключення

| Елемент | Звідки | Куди |
|---|---|---|
| LDR | 3V3 | вузол подільника |
| Резистор 10 кОм | вузол подільника | GND |
| Вузол подільника | — | GPIO4 (ADC1_CH3) |
| Резистор 330 Ом | GPIO16 | анод LED |
| Катод LED | — | GND |

При такому підключенні більше світла означає менший опір LDR і вищу напругу на ADC. Тобто «темно» відповідає малим значенням ADC.

### Вибір пінів

- **GPIO4 (ADC1_CH3)** — канал ADC1, не є strapping-піном. ADC2 не використовується, бо конфліктує з Wi-Fi.
- **GPIO16** — вільний GPIO. Уникалися GPIO35–37 (octal PSRAM на N16R8), GPIO19/20 (USB), GPIO0/3/45/46 (strapping), GPIO48 (вбудований RGB LED).

### Виміряні значення ADC (raw, 12 біт, атенюація 12 dB)

| Умови | raw |
|---|---|
| LDR накритий | 151 |
| Кімнатне освітлення | 805 |
| Ліхтарик | 3810 |

## Програмна частина

### Параметри

| Параметр | Значення |
|---|---|
| Канал ADC | ADC1_CH3 (GPIO4) |
| Атенюація | `ADC_ATTEN_DB_12` |
| Період зчитування | 50 мс |
| Розмір вікна SMA | 16 відліків (≈ 0.8 с) |
| Поріг увімкнення | 300 |
| Поріг вимкнення | 450 |

### Simple Moving Average

SMA реалізована на кільцевому буфері з біжучою сумою. На кожному кроці з суми віднімається найстаріше значення і додається нове, тому складність оновлення O(1) незалежно від розміру вікна.

Поки буфер не заповнений, сума ділиться на фактичну кількість відліків, а не на розмір вікна. Інакше одразу після старту середнє було б заниженим через нулі в буфері, що призводило б до хибного ввімкнення LED.

### Гістерезис

Стан світлодіода — це автомат на два стани:

- **LED вимкнений** → вмикається, якщо `SMA < 300`.
- **LED увімкнений** → вимикається, якщо `SMA > 450`.
- Між порогами стан не змінюється.

Пороги обрані навколо середнього геометричного значень «темно» і «кімната» (√(151 × 805) ≈ 350), бо опір LDR змінюється приблизно логарифмічно від освітленості. Зазор у 150 одиниць перекриває залишковий шум після фільтрації.

## Структура проєкту

```
main/
├── main.c          # ініціалізація ADC/GPIO, основний цикл, гістерезис
├── sma.h           # інтерфейс SMA
├── sma.c           # реалізація SMA
└── CMakeLists.txt
```

## Збірка та запуск

```bash
idf.py set-target esp32s3
idf.py build
idf.py -p <PORT> flash monitor
```

## Результат

Формат виводу в консоль: `raw,sma,led`. Під час перемикання додатково виводиться рядок `LED -> ON/OFF (avg=...)`.
```text
169,369,0
159,338,0
164,309,0
LED -> ON (avg=280)
159,280,1
...
841,411,1
LED -> OFF (avg=454)
871,454,0
```

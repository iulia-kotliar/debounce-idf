# Модуль 3.3 — Широтно-імпульсна модуляція (PWM)

Керування яскравістю світлодіода та швидкістю вала двигуна двома незалежними
потенціометрами на ESP32-S3.

## Обладнання

| Компонент | Модель / номінал |
|---|---|
| Плата | YD-ESP32-S3 N16R8 (16 MB flash, 8 MB PSRAM) |
| Двигун | колекторний TT-мотор з редуктором, 3–6 В |
| Транзистор | 2N2222A (NPN, TO-92) |
| Світлодіод | 5 мм червоний |
| Потенціометри | 2 × 10 кОм (B10K) |
| Резистори | 330 Ом (світлодіод), 330 Ом (база транзистора) |
| Діод | 1N4007 (захист від зворотної ЕРС) |
| Конденсатор | 100 нФ (керамічний, на клемах двигуна) |
| Живлення двигуна | модуль MB102, 5 В |

Середовище: ESP-IDF, драйвери `ledc` та `esp_adc/adc_oneshot`.

## Схема підключення

### Потенціометри

Обидва підключені однаково: крайні виводи на `3V3` і `GND`, середній — на вхід АЦП.

| Потенціометр | Середній вивід | Канал АЦП |
|---|---|---|
| Яскравість | GPIO1 | ADC1_CH0 |
| Швидкість | GPIO2 | ADC1_CH1 |

Використано ADC1, оскільки ADC2 на ESP32-S3 конфліктує з Wi-Fi.
Піни GPIO35–37 не задіяні — вони зайняті octal PSRAM на цій платі.

### Світлодіод

```
GPIO15 ── 330 Ом ──┤>├── GND
```

### Двигун

```
                 +5 В (MB102)
                     │
                     ├──────────┐
                     │          │
                  [двигун]    [1N4007]   катод до +5 В
                     │          │
                     ├──────────┘
                     │
                 колектор
GPIO16 ── 330 Ом ── база (2N2222A)
                 емітер
                     │
                    GND
```

Конденсатор 100 нФ припаяний безпосередньо на клемах двигуна — гасить
іскріння щіток, яке інакше збиває показники АЦП.

Земля модуля живлення обов'язково з'єднана з `GND` плати. Без спільної
землі транзистор не має опорної точки й не відкривається.

## Незалежність каналів

Кожен канал використовує **власний таймер LEDC**:

| Канал | GPIO | Таймер | Частота | Роздільність |
|---|---|---|---|---|
| Світлодіод | 15 | `LEDC_TIMER_0` | 5 кГц | 10 біт |
| Двигун | 16 | `LEDC_TIMER_1` | 20 кГц | 10 біт |

Оскільки таймери різні, зміна скважності або частоти одного каналу не
впливає на інший. Частоту двигуна обрано вище 20 кГц, щоб обмотка не
свистіла в чутному діапазоні.

## Особливості реалізації

**Усереднення АЦП.** Кожен вимір — середнє з 16 відліків. Без цього
значення дрижать у межах ±25 одиниць, і світлодіод помітно тремтить.

**Нелінійна характеристика світлодіода.** Око сприймає яскравість
нелінійно, тому лінійна скважність виглядає так, ніби світлодіод
спалахує на першій чверті ходу ручки. Застосовано квадратичну залежність:

```c
duty = linear² / PWM_MAX
```

**Мертва зона двигуна.** Нижче ~35% скважності вал не рушає з місця,
двигун лише гуде. Тому нижня частина ходу ручки трактується як зупинка,
а решта діапазону розтягується від порогу рушання до максимуму.

## Збірка та запуск

```bash
idf.py set-target esp32s3
idf.py build
idf.py -p /dev/ttyACM0 flash monitor
```

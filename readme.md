# Модуль 3.5. Керування сервоприводом за допомогою PWM

Потенціометр керує положенням валу сервоприводу SG90 у пропорції 1:1 на ESP32-S3 (ESP-IDF).

## Компоненти

| Компонент | Опис |
|---|---|
| ESP32-S3 DevKit (YD-ESP32-S3 N16R8) | мікроконтролер |
| Сервопривід Tower Pro SG90 | хід 0–180°, керування PWM 50 Гц |
| Потенціометр B10K | 10 кОм, лінійний, хід ~270° |
| Електролітичний конденсатор 470 мкФ / 25 В | згладжування просадок живлення серво |
| Макетна плата, дроти | |

## Схема

```
                         ┌─────────────────────────┐
     Потенціометр        │      ESP32-S3 DevKit    │         Сервопривід SG90
        B10K             │        (YD N16R8)       │
    ┌────────────┐       │                         │
    │  вивід 1   ├───────┤ 3V3                     │
    │  повзунок  ├───────┤ GPIO1 (ADC1_CH0)        │
    │  вивід 3   ├──┐    │                   5V    ├────┬──────── червоний   (VCC)
    └────────────┘  │    │                  GPIO5  ├────┼──────── помаранч.  (PWM)
                    │    │                   GND   ├──┬─┼──────── коричневий (GND)
                    │    │  GND                    │  │ │
                    │    └──┬──────────────────────┘  │ ═╪═ C1 470 мкФ
                    │       │                         │  │  (+ до 5V, − до GND)
                    └───────┴────────── спільна GND ──┴──┘
```

| Компонент | Вивід | ESP32-S3 |
|---|---|---|
| Потенціометр | крайній 1 | 3V3 |
| Потенціометр | повзунок | GPIO1 (ADC1_CH0) |
| Потенціометр | крайній 3 | GND |
| Серво | червоний (VCC) | 5V |
| Серво | помаранчевий (сигнал) | GPIO5 (LEDC) |
| Серво | коричневий (GND) | GND |
| C1 470 мкФ | + / − | 5V / GND, біля роз'єму серво |

Потенціометр живиться від 3V3, бо вхід АЦП ESP32-S3 не витримує напругу понад 3.3 В. Серво живиться від 5V; конденсатор C1 гасить стрибки струму при русі серво і запобігає перезавантаженню плати (brownout).

## Як це працює

**PWM (LEDC).** Таймер LEDC працює на 50 Гц (період 20 мс) з роздільністю 14 біт. Кут серво задається шириною імпульсу: 500 мкс відповідає 0°, 2400 мкс відповідає 180°.

**Вимір положення ручки (ADC).** Напруга з повзунка зчитується через `adc_oneshot` з калібруванням curve fitting (атенюація 12 дБ) і усереднюється по 16 вимірах для зменшення шуму.

**Пропорція 1:1.** Напруга переводиться в механічний кут ручки від крайнього лівого положення:

```
кут_ручки = U_повзунка × POT_TRAVEL_DEG / POT_VCC_MV = U × 270° / 3300 мВ
```

Отриманий кут без масштабування передається на серво, тому поворот ручки на 1° повертає вал серво на 1°.

**Обрізання діапазону.** Потенціометр має хід ~270°, серво 180°. Спільна частина діапазонів 0–180° від крайнього лівого положення. Коли ручка повертається далі за 180°, серво залишається на упорі 180°, а в лозі з'являється позначка `[limit]`. Решта ходу потенціометра (180–270°) не використовується.

**Стабільність.** Гістерезис 0.7°: серво і лог оновлюються тільки при реальній зміні положення ручки, без тремтіння в стані спокою.

## Налаштування

Константи на початку `main/main.c`:

| Константа | Значення | Опис |
|---|---|---|
| `POT_TRAVEL_DEG` | 270 | повний механічний хід потенціометра |
| `POT_VCC_MV` | 3300 | напруга живлення потенціометра |
| `SERVO_MIN_US` / `SERVO_MAX_US` | 500 / 2400 | ширина імпульсу для 0° і 180° |
| `SERVO_INVERT` | 0 | 1, якщо серво крутиться в протилежний бік від ручки |
| `HYSTERESIS_X10` | 7 | мінімальна зміна кута для оновлення, у десятих градуса |

## Збірка і запуск

Потрібен ESP-IDF v5.x (для версій до 5.2 замінити `ADC_ATTEN_DB_12` на `ADC_ATTEN_DB_11`).

```bash
idf.py set-target esp32s3
idf.py build flash monitor
```

## Результат виконання

Поворот ручки від крайнього лівого положення до обмеження (фрагмент логу):

```
I (30429) servo_pot: angle from left:   0.0 deg  (pot    0 mV)
I (31729) servo_pot: angle from left:   2.9 deg  (pot   36 mV)
I (31809) servo_pot: angle from left:  12.5 deg  (pot  153 mV)
I (32049) servo_pot: angle from left:  41.5 deg  (pot  508 mV)
I (32289) servo_pot: angle from left:  73.0 deg  (pot  893 mV)
I (32409) servo_pot: angle from left:  89.8 deg  (pot 1098 mV)
I (32629) servo_pot: angle from left: 113.3 deg  (pot 1385 mV)
I (32809) servo_pot: angle from left: 143.0 deg  (pot 1748 mV)
I (32969) servo_pot: angle from left: 168.3 deg  (pot 2057 mV)
I (33029) servo_pot: angle from left: 177.6 deg  (pot 2171 mV)
I (33049) servo_pot: angle from left: 180.0 deg  (pot 2214 mV)  [limit]
```

Кут змінюється лінійно з напругою на повзунку. Серво досягає 180° приблизно при 2.2 В, що відповідає 2/3 ходу потенціометра (180° з 270°); подальший поворот ручки обрізається.
